# Paper Trading Dashboard

Live view of a **simulated (paper) crypto trading** account. No real money, no exchange account, no real orders.

https://tylerbbush.github.io/paper-trading-dashboard/

`index.html` is the self-contained dashboard; `data.json` is the latest account snapshot, refreshed by the trader roughly every 15 minutes. Open-position prices are fetched live from the Coinbase public API in the browser.
